# Data

evidencelocker ships no third-party datasets. Everything under `testdata/`
is synthetic and was created for this project.

| Data | Location | Source | License |
|---|---|---|---|
| Fixture host trees `baseline`, `compromised`, `macos` (~660 KB, 169 files) | `testdata/hosts/` | Generated by `internal/fixtures` (`make fixtures`); committed and checked by `TestFixturesUpToDate` | MIT (this repository) |
| Merkle known-answer vectors (8 leaf inputs and their roots) | `pkg/merkle/merkle_test.go` (`TestKnownAnswer`) | Leaf inputs and expected roots from the RFC 6962 reference test suite used by Google's certificate-transparency implementations | Apache-2.0 (upstream test vectors; facts reproduced in a test) |
| Fuzz regression seed | `pkg/merkle/testdata/fuzz/FuzzVerifyInclusion/` | Produced by `go test -fuzz` in this repository | MIT (this repository) |

## What the fixtures contain

* The "binaries" are 3-line inert shell scripts
  (`# evidencelocker fixture stand-in for <name>; inert.`). Nothing executable
  is malicious, and no real malware or exploit code is included anywhere.
* "Attacker" addresses are in the RFC 5737 documentation ranges
  (`203.0.113.0/24`, `198.51.100.0/24`) and are not routable.
* SSH keys in `authorized_keys` are SHA-256 outputs formatted as ed25519 key
  blobs. They are not real keys, and no private keys exist for them.
* `var/run/utmp` files are written with `users.EncodeUtmp`.
* `/proc` trees are text files and symlinks that mimic procfs formats
  (`status`, `cmdline`, `stat`, `exe`, `fd/*`, `net/tcp`).

No dataset is downloaded at build or test time. `make check` needs no network
once Go modules are cached.
